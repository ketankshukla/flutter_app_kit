# flutter_app_kit

A reusable Flutter starter for shipping monetized Android apps. Clone it, rename it, swap the domain logic, ship. Designed for a solo dev pushing apps to the Google Play Store.

## What's inside

- **State:** Riverpod 2
- **Routing:** go_router with auth + onboarding redirects
- **Auth:** Firebase Auth (email + Google + anonymous-first; auto-links anonymous → Google on upgrade)
- **Payments:** Google Play Billing via [RevenueCat](https://www.revenuecat.com/) — change paywall copy/prices without redeploys
- **Paywall:** monthly + annual selector with "BEST VALUE" tag, restore, trial copy, terms/privacy links (Play-compliant)
- **Feature gating:** wrap any premium widget in `FeatureGate(featureName: ..., child: ...)` — 1 line
- **Onboarding:** 3-screen swipeable carousel with skip
- **Settings:** account, subscription status, manage in Play, restore, sign out, **delete account** (Play-required)
- **Push:** FCM wired up (you add notification handlers per app)
- **Analytics:** Firebase Analytics + Crashlytics with a clean `Analytics.track(event, props)` API and `AnalyticsEvents` constants
- **Remote Config:** flip paywall headlines, free-tier limits, feature flags from the Firebase console
- **Theming:** Material 3, light + dark, single color tokens file
- **Legal:** privacy policy + terms templates (`docs/`)
- **CI:** GitHub Actions workflow builds signed AAB on `v*` git tag

## Repo layout

```
lib/
  main.dart                 # entry: zone guard + Firebase + Hive + Riverpod + RC bootstrap
  app.dart                  # MaterialApp.router
  firebase_options.dart     # generated by `flutterfire configure` (gitignored)
  core/
    analytics/              # Analytics wrapper + event constants
    config/                 # Env (compile-time secrets) + AppConfig

    router/                 # go_router with auth/onboarding redirect logic
    theme/                  # color tokens + Material 3 theme
    widgets/                # FeatureGate, LoadingView, ErrorView
  features/

    onboarding/             # 3-screen carousel
    paywall/                # PaywallScreen, PurchasesService, entitlementProvider

    home/                   # demo home with free + gated tiles
    legal/                  # in-app viewer pointing at hosted policy
  shared/
    providers/              # sharedPrefsProvider
    services/               # RemoteConfigService

docs/
  SETUP.md                  # first-time setup, ~1 evening

  TERMS_TEMPLATE.md

scripts/
  install-flutter.ps1       # Windows 11 PowerShell installer

.github/workflows/
  android-build.yml         # signed AAB on tag push
```

## Quick start

```powershell
# 1. Install Flutter on Windows
.\scripts\install-flutter.ps1

# 2. Open a NEW PowerShell window, then:
flutter doctor
flutter doctor --android-licenses

# 3. Generate Android platform code (preserves all our lib/ files)
flutter create . --org com.ketankshukla --project-name flutter_app_kit --platforms=android

# 4. Wire Firebase
dart pub global activate flutterfire_cli
flutterfire configure   # creates lib/firebase_options.dart + android/app/google-services.json

# 5. Install dependencies
flutter pub get

# 6. Run on emulator or device
flutter run
```

Then see `docs/SETUP.md` for RevenueCat, signing keystore, and Play Console steps.

## Clone-and-rename for a new app

```powershell
# From a fresh location:
git clone https://github.com/ketankshukla/flutter_app_kit.git my_new_app
cd my_new_app
Remove-Item -Recurse -Force .git
git init

# Rename package + bundle id:
# Edit pubspec.yaml -> name + description
# Edit android/app/build.gradle -> applicationId
# Re-run: flutter create . --org com.yourcompany --project-name my_new_app
# Re-run: flutterfire configure  (point at NEW Firebase project)
# Replace lib/features/home with your app's actual feature.
```

## What this kit does NOT include (intentional)

- A specific feature domain — that's per-app (e.g. VoiceDesk, SnapReceipt). The home screen has stub tiles to be replaced.
- iOS configuration — Android only for now. iOS support is one `flutter create` flag away.
- A backend — Firebase free tier handles auth + Firestore + Crashlytics for most starters. AI features will need a serverless function (Cloud Functions / Vercel / etc.).
